# RFM-сегментация и K-means кластеризация клиентов интернет-магазина

Сегментация клиентов британского онлайн-магазина подарков и товаров для дома по покупательскому поведению: RFM-скоринг и кластеризация K-means, сравнение двух подходов и рекомендации по каждому сегменту.

## Данные

[Online Retail II (UCI Machine Learning Repository)](https://archive.ics.uci.edu/dataset/502/online+retail+ii)


## Что сделано

1. **Очистка данных** — удалены строки без `CustomerID`, отмены (счета на `C`), строки с `Quantity ≤ 0` и `Price ≤ 0`, полные дубликаты. Осталось 392 693 строки, 4 338 клиентов, 18 532 заказа, выручка £8,89 млн.
2. **EDA** — выручка по месяцам (пик в ноябре 2011 — предрождественский сезон), топ стран (Великобритания — 82% выручки).
3. **RFM-метрики** — Recency, Frequency, Monetary для каждого клиента; анализ распределений и логарифмирование тяжёлых хвостов.
4. **RFM-скоринг** — баллы 1–5: квинтили для R и M, фиксированные границы для F (из-за большого числа клиентов с одним заказом). 10 сегментов: Champions, Loyal Customers, At Risk, Can't Lose Them, Hibernating и др.
5. **K-means** — log-преобразование + стандартизация, выбор k по методу локтя и silhouette score, k = 4. Визуализация кластеров в проекции PCA.
6. **Сравнение подходов** — таблица сопряжённости RFM-сегментов и кластеров, Adjusted Rand Index = 0,44.
7. **Рекомендации** — конкретные действия и метрики успеха для каждого сегмента.

## Ограничения

- Период — один год, сезонность влияет на Recency.
- Последний месяц (декабрь 2011) неполный.
- Не учтены категории товаров, маржинальность и каналы привлечения.
- Monetary сильно скошена из-за оптовиков — для них нужен отдельный анализ.
- Эффект рекомендаций нужно проверять A/B-тестами.
